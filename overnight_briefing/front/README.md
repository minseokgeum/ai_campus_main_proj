# 당신이 잠든 사이에: 고객 화면 (front)

증권사 앱 안에 들어가는 아침 브리핑을 실제 서비스 화면처럼 만든 것이다. 휴대폰 화면 하나와, 그 옆의 시연 조작판으로 이루어진다.
Streamlit 앱(`src/app`, 8510)은 검증·연구용 화면으로 그대로 두고, 고객이 보는 화면은 여기서 만든다.

## 열기

```bash
~/4Digit/.venv/bin/python ~/4Digit/src/front/serve.py     # http://127.0.0.1:8520
```

`열기.command`를 두 번 눌러도 된다(서버가 꺼져 있으면 켜고 브라우저를 연다). 이 컴퓨터에서만 열린다.
주소 뒤 `#T=20261111&slot=0811&acct=A&tab=brief`로 날짜·시각·계좌·화면을 바로 고를 수 있다(`&llm=1` LLM 자리 표시, `&dark=1` 어두운 화면).

## 구조

| 파일 | 하는 일 |
|---|---|
| `bundle.py` | 하루치 묶음을 만든다. 계산은 하지 않고 `src/app/core/data.py`의 읽기 함수를 그대로 쓴다(같은 파일, 같은 숫자). |
| `serve.py` | `web/` 정적 파일과 `/api/meta`, `/api/day/<T>`를 내준다. 묶음은 60초만 기억한다. `--export <폴더>`는 같은 묶음을 정적 파일로 내보낸다. |
| `web/js/app.js` | 상태(날짜·시각·계좌·화면·수량 가정·시가 가정)와 누르기 처리 |
| `web/js/screens.js` | 화면 다섯 개(브리핑·밤사이·소식·관계·기록)와 아래에서 올라오는 창(종목·소식·계좌·설명) |
| `web/js/band.js` | 노란띠 한 줄. 양 끝·예상 시가 숫자를 늘 보여 주고, 누르거나 끌면 '그 값에 열리면'을 보여 준다 |
| `web/js/charts.js` | 밤 흐름 선, 기록 막대, 종목 지난 기록, 관계 그림(SVG) |
| `web/js/llm.js` | LLM이 채울 자리 목록(입력·출력·금지)과, 지금 그 자리를 채우는 규칙 문장 |
| `web/css/app.css` | 색·간격 토큰과 모든 부품. 어두운 화면은 토큰만 바꾼다 |
| `tests/smoke_front.py` | 모든 날짜 × 계좌 × 시각 × 화면을 열어 오류·빈 화면을 찾는다 |

## 화면에서 계산하는 것

브라우저가 하는 계산은 하나뿐이다: `수량 × 어제 종가 × 등락률`. 등락률은 예상 시가·범위 끝·장전 거래·실제 시가·사용자가 띠 위에서 고른 값 가운데 하나다.
나머지 숫자(범위, 믿을 정도, 기록)는 묶음에 있는 값을 그대로 보여 준다.

- 수량 − +: 띠 줄 안에서 바로 바꾼다. 길게 누르면 빨라지고, 숫자를 누르면 직접 적을 수 있다. 실제 주문과 이어지지 않는다.
- 띠 누르기·끌기: '이 값에 열리면' 내 금액을 보여 주고, 손을 떼면 그 값이 가정으로 남는다. 맨 위 합계도 가정 합계로 바뀐다.
- 띠 눈금은 한 화면의 모든 종목이 같이 쓴다(0 = 어제 종가 포함). 종목끼리 폭과 위치를 견줄 수 있다.

## 시연용 가정

- 계좌는 예시 계좌 A~J다. 계좌번호와 평균 단가는 가정이다. 평균 단가는 그 종목의 실제 과거 종가 하나(`bundle.BUY_DATES` 가운데 하루)를 쓴다.
- 조작판(날짜·시각·계좌·LLM 자리·어두운 화면)은 시연용이다. 실제 서비스에는 휴대폰 화면만 있다.
- 조작판의 '기록 종류'는 그 날 화면이 장 전에 고정한 기록인지, 개장 뒤 발행인지, 사후 계산·과거 재생인지 알려 준다. 휴대폰 화면 맨 아래에도 한 줄로 적는다.

## LLM 출력 자리

`web/js/llm.js`의 `SLOTS`가 원본이다. 화면에서는 조작판의 'LLM 출력 자리 표시'를 켜면 보라색 번호로 나온다.
지금은 ① 밤사이 요약 ④ 종목 한 줄 ⑤ 밤 흐름 한 줄을 규칙 문장(코드)으로, ② 기사 한 줄 제목 ③ 이어지는 이유를 뉴스 판정 단계의 결과로 채운다.
LLM을 붙일 때는 묶음에 문장 칸을 더하고, `llm.js`의 규칙 문장을 그 칸이 비었을 때만 쓰도록 바꾼다.
