코드 함수 사전

야간선물 모델 코드(research/overnight_backtest)의 파일과 함수가 무슨 일을 하는지 쉬운 말로 적었어요. 함수 252줄, 2026-11-03 코드 기준.

파일 이름으로 찾으면 그 파일의 함수가 다 보여요.

읽는 법

파일 = 일을 묶은 상자, 함수 = 한 가지 일

파일은 비슷한 일을 하는 함수를 모은 상자예요. 함수는 "재료를 받아서 한 가지 일을 하고 결과를 돌려주는" 단위예요. 괄호 안의 이름은 함수가 받는 재료예요. 예를 들어 finished(session, d, now)는 "어느 장(session), 어느 날(d), 지금 시각(now)을 받아서 그 장이 끝났는지 알려 준다"는 뜻이에요.

파일 옆 표시는 지금 상태예요. 지금 화면에 쓰임은 아침 카드를 만들 때 실제로 도는 파일, 실험은 기준을 정하려고 한 번 돌린 실험, 재검증·실시간 기록 안전장치·관리는 결과를 다시 확인하거나 기록을 지키는 도구예요.

아침 카드를 이해하려면 핵심 7개 파일만 보면 돼요. 나머지는 "이 이름이 뭐였지?" 할 때 검색칸으로 찾아보는 용도예요.

이름 짓는 습관

이름의 앞뒤 글자만 봐도 대충 무슨 일인지 알 수 있어요

이름에 이게 있으면보통 이런 뜻
main명령으로 파일을 실행할 때 처음 도는 곳. 나머지 함수를 순서대로 부른다.
_이름 (밑줄로 시작)그 파일 안에서만 쓰는 작은 도우미. 다른 파일에서는 부르지 않는다.
sha · sha256 · digest · key_sha파일이나 값의 해시(SHA-256). 한 글자만 바뀌어도 값이 달라져서, 몰래 바뀌지 않았는지 확인할 때 쓴다.
validate_ · verify_ · require · need · check_검사하고, 틀리면 그 자리에서 멈춘다. 틀린 채로 계산이 계속되지 않게.
load_ · read_파일을 읽어 표로 만든다.
build_ · make_ · assemble · construct여러 재료를 합쳐 큰 표를 만든다.
prior_ · past_ · _before그날보다 앞선 자료만 쓴다. 미래 값이 섞이지 않게 하는 표시.
fit_과거 자료로 계수(기울기 등)를 배운다.
predict · forecast_배운 계수로 그날 값을 계산한다.
daily · describe · summarize · evaluate채점하고 요약한다.
compare두 후보를 같은 종목·일로 맞춰 어느 쪽이 나은지 본다.
bootstrap_mean · bs · block_날짜를 블록(5·10거래일) 단위로 다시 뽑는 블록 부트스트랩. 차이가 우연인지 본다.
holm여러 개를 한꺼번에 시험할 때 p값을 엄격하게 고친다(Holm 보정). 우연히 하나쯤 통과하는 것을 막는다.
nw_pNewey–West p값. 붙은 날끼리 비슷한 점(자기상관)을 고려한 p값.
stage_실험 단계. 개발 단계(design)와 최종 검증 단계(sealed).
run · execute · once실험이나 수신을 실제로 돌린다.
approval · verify_approval승인 파일이 있어야만 돈다. 실수로 실행되는 것을 막는다.
write_x · exclusive새 파일로만 쓴다. 같은 이름이 있으면 실패한다(덮어쓰기 금지).
synthetic · test_가짜(합성) 자료로 시험한다. 실제 시장 자료가 아니다.
minimum · min_periods최소 관측 수. 창 안의 유효 관측이 이보다 적으면 값을 만들지 않고 결측(NaN)으로 둔다. 0이나 평균으로 채우지 않는다.
window창 길이. 그날 이전 유효 관측 가운데 최근 몇 개를 쓰는지(거래일 매칭 표일이 아니라 관측 개수).
lam (λ)지수가중 감쇠. 하루 오래될 때마다 가중치를 0.94배로 줄인다. 약 11거래일 지나면 가중치가 절반.
level · alpha (α)구간 수준. level 0.8 = 80% 구간, alpha = 1 − level = 0.2.
block · reps · seed블록 부트스트랩의 블록 길이(거래일), 반복 횟수, 난수 씨앗(같은 결과 재현용).
cutoff자료 기준 시각. '06:00'이면 06시까지 알 수 있는 값만, '08:11'이면 NXT 08:10 봉까지.

열 이름 사전

함수들이 주고받는 표의 칸 이름. 함수 설명에 자주 나와요

열 이름뜻
T예측 대상 거래일(오늘). 문자열, 예: 20261103.
DT 바로 앞 KRX 거래일. 기준 종가와 야간 세션(D 18:00 ~ T 06:00)이 이 날짜로 저장된다.

ax|x|, 야간 수익률의 절댓값(방향을 뺀 야간 변동 크기). 단위 수익률. 예전 이름 '밤 크기'.

pcD일 정규장 종가(기준 종가). 단위 원. 확정 D 15:30.
M1절편 포함 회귀 예측 a + β·x. 단위 수익률. a, β는 그날 이전 유효 관측 250개(최소 120)로 추정.
F2조정 베타 예측 ((β⁰ + 1) ÷ 2)·x. β⁰는 절편 없는 기울기 Σxy ÷ Σx². 단위 수익률.
r2절편 포함 회귀의 결정계수 R²(0~1). 그날 이전 유효 관측 250개에서 x가 y 변동을 설명한 비율.
H시가 갭 점추정치(화면 이름 06시 참고값). r2 < 0.3이면 M1, 아니면 F2. 단위 수익률. 확정 T 06:00.
e예측오차 = y − H. 단위 수익률(표시는 %p).
g구간 중심 열. 06시 표(z)에서는 H와 같다. 08시 표(n)에서는 NXT 프리마켓 갭 = NXT 08:10 체결가 ÷ pc − 1(과거 분석의 T 08:11 사용 가정, 실시간 봉 의미·수신 지연 미확인).
sd06그날 이전 (y − x)의 지수가중 RMS(최근 250개, 최소 60, λ 0.94). 종목이 야간선물과 따로 움직인 정도. 단위 수익률.
lsdlog(sd06). 방향 일치 확률의 설명변수.
sd0806시 표에서는 그날 이전 예측오차 e의 지수가중 RMS(최근 250개, 최소 20, λ 0.94) = 설계서의 s^H. 예측구간 폭의 기본 단위. 단위 수익률. 이름의 08은 원래 08:11 표에서 쓰던 이름이 남은 것.

L80 · U80 · L90 · U90예측구간의 아래 끝·위 끝(80%·90%). 단위 수익률.
size크기. 06시 표에서는 |H|, 08시 표에서는 |g|. 단위 수익률.

mon · hol · exp · fomc · cpi · nfp0/1. 월요일 / 연휴 뒤(D와 T 사이에 쉰 평일이 있음) / 옵션 만기일 / FOMC·CPI·고용 발표 다음 거래일.
