항목내용
입력T, 실행 시각, KIS 자격 증명, 연구 자료(data/)
처리⓪ KIS 국내휴장일조회로 T의 개장일 여부를 확인한다. 휴장일이면 자료를 받지 않고 refresh_manifest.json에 사유만 남긴 뒤 정상 종료한다. 조회에 실패하면 주말만 막고 확인 방법을 기록한다. ① 이어받을 자료 폴더를 정한다(--base). 기본값 auto는 같은 이름 폴더에 자료가 있으면 그 폴더, 없으면 이름이 더 앞인 가장 최근 자료 폴더, 둘 다 없으면 연구 data/ 사본이다. 이어받은 자료의 마지막 날짜 다음 날부터만 받는다. ② 선물 근월물 일봉(주간 시장코드 F, 야간 CM)을 주간·야간 가운데 더 이른 마지막 날짜의 다음 날부터 T까지 받아, 종료된 세션만 추가한다. 주간은 그날 15:50 이후, 야간은 다음 날 06:05 이후를 종료로 본다. ③ 200종목 일봉 시가·종가(시장 J)를 마지막 확정 종가일까지 받는다. 확정 종가일은 실행 시각이 16:00 이후면 T, 그 전이면 T−1이다. ④ 코스피 200 지수 일봉을 같은 기간까지 받는다. ⑤ 지정한 날짜의 NXT 1분봉(시장 NX, 08:00~08:10)을 200종목 받는다. 이미 있는 지난 날짜는 받지 않고, 실행일 당일은 08:11 이후에만 받으며, 미래 날짜는 받지 않는다. 새로 받을 행이 없으면 기존 표를 그대로 둔다

수용 기준휴장일에는 자료를 받지 않는다. 진행 중인 세션의 행이 0건이다. 기존 키(날짜·세션, 날짜·종목, 날짜·종목·분)의 행은 바뀌지 않는다. 연구 data/는 바뀌지 않는다

3.11 FR-10 아침 카드 생성·저장

항목내용
입력FR-05 ~ FR-09 결과, 규칙·코드·입력 해시
처리§4.3 형식의 JSON과 본문의 SHA-256을 같은 이름의 .sha256 파일로 저장한다. slot은 계산 전에 결정하며 0730에서는 당일 NXT 등급을 계산하지 않는다. 실제 날짜 입력(--root)에는 --slot이 필수이고, 과거 재생에서만 생략 시 등급이 있으면 0811, 없으면 0730으로 선택한다. CLI는 실제 생성 시각 issued_at, 목표 표시 시각 slot_nominal_at, 둘의 관계 timing_status를 기록한다. 휴장일이면 status = holiday, 야간 신호가 무효이면 status = no_signal과 사유(reason, reason_text)만 담은 상태 카드를 만든다. 기준 종가가 양의 유한값이 아니거나 H·구간이 유한하지 않은 종목은 stocks에서 빼고 dropped에 코드를 남긴다. 전부 탈락하면 reason = no_eligible_stocks 상태 카드를 낸다
출력card_<T>_<slot>.json, card_<T>_<slot>.json.sha256(같은 이름이 있으면 _v2, _v3 …을 붙인 새 파일)
수용 기준기존 파일을 덮어쓰지 않는다. JSON에 NaN·무한대가 없다. after_open은 과거 재생의 --with-outcome에서만 넣고 실제 날짜 입력에서는 이 옵션을 거부한다. 과거 재생도 0730이면 nxt_dir_match는 null이다. 슬롯·모드·생성 시각만으로 장전 봉인·I16 승인·미래 검증 기록을 인정하지 않는다

실제 날짜 입력은 다음 준비 상태를 별도로 확인한다. 수집 기록의 fetched는 수신 성공이 아니라 수집 시도 날짜이며, 기록 통과 자체가 자료 품질이나 I16 자격을 보증하지 않는다.

경계확인·처리
갱신 기록refresh_manifest.json이 NaN·무한대 없는 객체이며 시간대 있는 시작·완료 시각, 시작 ≤ 완료 ≤ 현재 시각, trading_day.date = T와 bool open을 확인한다. 없음·형식 오류·미완료·시간 순서 오류·미래 시각·대상일 불일치는 패널을 읽기 전에 data_not_ready 상태 카드로 남긴다
야간 자료signal_T.D가 확인되고 D < T이며 갱신 시작 ≥ D+1 06:05여야 한다. D를 확인하지 못하거나 너무 일찍 갱신한 경우, 야간 행·거래일 매칭이 누락된 경우 data_not_ready로 남긴다. 실제 날짜 입력의 누락 원인을 곧바로 휴장·만기일로 단정하지 않는다
0730당일 NXT 등급은 요청하지 않는다(grade_status.status = not_requested). 야간 자료 준비와 모형 유효성이 충족되면 종목 범위만 산출한다
0811갱신 시작 ≥ T 08:11, premarket_days.asked·fetched에 T 포함, skipped에는 T 없음, 당일 n 표와 유한하고 0이 아닌 g가 있어야 등급 계산을 허용한다. 준비 불충족이면 등급만 null로 두고 사유를 기록하며, 야간 자료로 계산할 수 있는 H·범위는 유지한다

야간 수집 조건을 통과한 뒤 확인된 신호 무효나 유효 종목 전부 탈락은 기존 no_signal로 남는다. data_readiness.status = collection_gate_passed와 카드 status = ok는 같은 뜻이 아니다.

5.2 A-01 시가 갭 점추정치

종목 i, 대상일 T에 대해, T 이전 유효 관측 최근 250개(최소 120개)로 계산한다.

\[\beta=\frac{S_{xy}}{S_{xx}},\quad a=\bar y-\beta\bar x,\quad R^2=\frac{S_{xy}^2}{S_{xx}S_{yy}},\quad \beta^0=\frac{\sum xy}{\sum x^2}\]
\[M1=a+\beta x_T,\qquad F2=\frac{\beta^0+1}{2}x_T,\qquad H=\begin{cases}M1,&R^2<0.3\\F2,&R^2\ge0.3\end{cases}\]

\(S_{xx}, S_{yy}, S_{xy}\)는 평균을 뺀 제곱합·곱합이다. \(S_{xx}\), \(S_{yy}\), \(\sum x^2\) 가운데 하나라도 0이면 결측이다.

\(F2\)는 원점을 지나며 절편을 두지 않는다. 기울기는 절편 포함 회귀의 \(\beta\)가 아니라 절편 없는 \(\beta^0\)를 쓴다. 절편을 넣은 변형(\(a + \frac{\beta+1}{2}x_T\))은 E80에서 평균 절대오차가 0.28% 커져 채택하지 않았다(모델 설계서 §5.1·§9).

5.4 A-03 예측구간 S1

T마다 다음을 수행한다.

  1. 개발 종목 행 가운데 y, H, \(s^H\)가 있고 \(s^H > 0\)인 행에서 T 이전 날짜를 모은다. 가장 최근 20거래일을 보정 표본 C, 그 앞 전부를 학습 표본 L로 둔다. L이 60거래일 미만이면 산출하지 않는다.
  2. L에서 \(|x|\)의 1%·99% 분위 \(q_{01}, q_{99}\)로 자른 값의 평균 \(\mu\), 표준편차 \(\sigma\)(0이면 1)를 구하고 \(z = (\operatorname{clip}(|x|, q_{01}, q_{99}) - \mu) / \sigma\)로 표준화한다.
  3. 목표 \(\ell = \log(|y - H| / s^H + 0.001)\)를 \([1, z]\)에 회귀한다. 가중치는 날짜 가중치 \(w_0\)에서 시작하고, 8회 반복하며 잔차 \(r\), 강건 척도 \(c = \max(\operatorname{MAD}(r)/0.67448975,\ 10^{-6})\)로 \(w = w_0 \cdot \min(1,\ 1.35c/|r|)\)를 갱신한다. 결과 계수는 \(b_0, b_1\)이다.
  4. 척도 \(\hat\sigma = s^H \exp(\operatorname{clip}(b_0 + b_1 z, -8, 8))\).
  5. C에서 \(u = |y - H| / \hat\sigma\)를 구하고, 날짜 가중 누적 비율이 0.8(0.9) 이상이 되는 첫 값을 \(\hat q_{0.8}\)(\(\hat q_{0.9}\))로 둔다.
  6. T의 종목별 \([L_{80}, U_{80}] = H \mp \hat q_{0.8}\hat\sigma\), \([L_{90}, U_{90}] = H \mp \hat q_{0.9}\hat\sigma\). T의 y는 사용하지 않는다.

5.6 A-05 방향 일치 등급

  1. 학습 표본: 개발 종목의 T 이전 08:11 표 행 가운데 g·y가 유한하고 \(g \ne 0\), \(y \ne 0\)인 행. 60거래일 미만이면 산출하지 않는다. 당일 추정도 유한하고 0이 아닌 g가 있는 종목만 대상으로 한다. slot = 0730이면 이 등급 계산을 호출하지 않는다.
  2. 목표: \(t = 1[\operatorname{sign}(g) = \operatorname{sign}(y)]\).
  3. 설명변수: \(|g|\), \(\log s^{06}\), \(R^2\)(계산열 size, lsd, r2). 학습 표본 중앙값으로 결측을 채우고 학습 표본 평균·표준편차(0이면 1)로 표준화한다. 당일 설명변수의 비유한값을 보정했다면 그 열 이름을 imputed_features에 기록한다. 이는 설명변수 보정이며 g가 없거나 0인 종목에 방향을 만들어 주지 않는다.
  4. 모형: L2 정규화 로지스틱 회귀(scikit-learn LogisticRegression, C = 1.0, max_iter = 400), 표본 가중치 = 날짜 가중치.
  5. 확률 p가 유한하고 0~1 안에 있을 때만 반올림 전 확률로 등급을 낸다. \(p \ge 0.90\) 높음, \(0.75 \le p < 0.90\) 보통, \(p < 0.75\) 낮음. 유효하지 않은 확률을 높은 등급으로 분류하지 않는다. 저장 p는 소수 3자리이므로 저장값으로 등급을 다시 판정하지 않는다(NFR-08).
