# 당신이 잠든 사이에 · 장 전 브리핑 (나은 브랜치)

밤사이 미국 장과 코스피200 야간선물이 이미 반영한 변화를, 내 보유 종목의 예상 시가·과거 통계 범위(노란띠)·금액으로 바꿔 보여 주는 증권사 앱 안 아침 브리핑이다.
이 폴더에는 최종 모델 코드, 화면 두 가지, 설계 문서가 들어 있다.

| 폴더 | 내용 | 실행 |
|---|---|---|
| `model/` | 최종 모델(예상 시가 H, 노란띠 S1, 08:11 믿을 정도 D08)과 매일 운영 스크립트, 뉴스 연결, 관계표 | `model/README.md` |
| `app/` | Streamlit 검증·연구 화면(아침 브리핑·밤사이 흐름·소식·관계표·예측 vs 실제·모델 한눈에·데이터 연결) | `streamlit run app/app.py` → 8510 |
| `front/` | 고객 화면(실제 서비스처럼 만든 모바일 화면, 띠 안 수량 −/+, 띠를 눌러 '그 값에 열리면' 금액) | `python front/serve.py` → 8520 |
| `docs/` | 서비스 아키텍처·기술 명세서·모델 설계서 v2·실험 장부·화면 설계·코드 함수 사전·숙지용 노트. 맨 위 탭으로 서로 이어진다 | 브라우저로 html 열기 |

## 어떻게 이어지나

```
model/workbench/live_refresh.py   끝난 장 자료 이어 받기(한국투자증권 KIS·DART·FDR)
        ↓
model/workbench/morning_card.py   07:30·08:11 아침 카드(종목별 H·노란띠·등급·주의 문구) → 해시로 고정
        ↓
model/workbench/news_morning.sh   밤사이 미국 기사 → 관계표 규칙·OpenAI 판정으로 국내 종목 연결 → 고정
        ↓
app/pipeline/*.py                 카드·야간 1분봉·뉴스를 화면용 파일로(app/data/)
        ↓
app/ (Streamlit)  ·  front/ (고객 화면)
        ↓
model/workbench/runs/claude_live_r1/check_open.py · e100_forward.py   개장 뒤 실제 시가로 채점, 규칙 확정 뒤 누적 기록
```

## 올리지 않은 것

공개 저장소라 가격·뉴스 원자료(`data/`, `live/`, 수백 MB), 실행 결과, API 키(`.env`)는 올리지 않았다. 팀 `.gitignore` 규칙과 같다.
화면을 띄우려면 `model/README.md`의 순서로 자료를 받아 만들거나, 원자료가 있는 컴퓨터에서 실행한다.
