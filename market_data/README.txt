  - 지수 구성종목 자료로 연결: 2,370개
  - 기업 페이지 관측으로 연결: 285개

- 과거 시점별 업종 이력이 아니며, 분류의 공식 효력 시작일은 검증되지 않았습니다.
- 자동 갱신 자료가 아니라 저장된 분류 자료입니다.

3. 원본에서 정리한 내용 (2026-11-09)
원본 sector_master_v1.json(2,874개 종목)에서 업종이 연결되지 않은 219개를 삭제하고 sector.json으로 이름을 바꿨습니다.
- KONEX 상장 107개: 서비스 대상이 아니라서 삭제했습니다. 제공처가 미분류로 표시한 종목이었습니다.
- 업종 미확정 우선주 112개 (KOSPI 110개, KOSDAQ 2개): 보통주가 아니라서 삭제했습니다.
  보통주가 아님은 종목코드 끝자리(0이 아님), 종목명(우, 우B, (전환) 등), 크레온 종목 목록의 보통주 여부로 확인했습니다.
- JSON 안의 metadata(종목 수, 상태별 집계), pending_review, usage_notes도 정리 결과에 맞게 고쳤습니다. 삭제 내역은 metadata.removed에 있습니다.
- 종목명은 최신 사명으로 고쳤습니다. 304840은 피플바이오에서 타임X AI로 바뀌었습니다(DART 기업 목록, 2026-11-03 변경). 옛 이름은 former_security_names에 남겼습니다.
- 보통주가 아니지만 업종이 연결된 116개는 남겨 두었습니다.
  스팩 68개, 리츠 23개, 부동산 투자회사 1개, 인프라 투자회사 2개, 해외 기업 22개(DR 10개, 외국 주권 12개)입니다.
  스팩·리츠·투자회사는 사업 회사가 아니므로 업종 뉴스 연결에는 쓰지 않습니다.

4. 사용 방법
- 사람이 확인할 때는 HTML을 먼저 여세요. 원문 출처 링크를 누르면 인터넷 연결이 필요합니다.
- 프로그램에서는 JSON의 stocks[종목코드].wi26.sector_code를 사용하세요.
- 업종 표시 이름은 sectors[업종코드].sector_name에서 조회할 수 있습니다.
- 종목코드는 앞자리 0이나 영문자가 있으므로 문자열로 유지하세요.
- review_required=true인 종목은 별도 검토 대상으로 관리하세요. 현재는 없습니다.
- 우선주는 이 자료에 없습니다. 우선주에 보통주의 업종을 쓰려면 따로 연결해야 합니다.
- service_industry의 서비스 세부 업종과 theme_tags는 아직 미설정입니다.
- 이 자료에는 섹터 지수 이력이나 지표 회귀 결과는 포함하지 않았습니다.
